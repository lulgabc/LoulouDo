# Task icons

The 48 task icons in `svg/` come from **Microsoft Fluent Emoji Flat**.

- Source: https://github.com/microsoft/fluentui-emoji
- Downloaded via: https://iconify.design/ (set `fluent-emoji-flat`)
- License: MIT, see `LICENSE.txt`
- Runtime copy: `src/assets/taskIcons.ts` (generated SVG strings used by `SvgXml`)

The app bundles these SVGs locally, so task icons work offline and look the same on iOS, Android and Web.
